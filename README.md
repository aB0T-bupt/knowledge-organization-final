# 北京地铁换乘与景点导览知识图谱

《现代知识组织与管理》期末大作业。覆盖北京城市轨道交通全网，收录 16 个精选景点，支持按线路找景点和一次换乘导览。

| 交付物 | 内容 |
| --- | --- |
| [知识图谱设计说明](知识图谱设计说明.md) | 类层级、属性、数据来源与统计口径 |
| [北京地铁知识图谱](北京地铁知识图谱.rdf) | RDF/XML，本体与实例可一并导入 Protégé |
| [应用文档](应用文档.md) | 场景、两条 SPARQL 查询、结果解读与截图 |

图谱有 **467 个领域实体**、**1068 条去重业务关系**和 **2645 条 RDF 三元组**。查询一返回 10 行，查询二返回 30 个换乘方案，覆盖 13 个景点。结果目录同时提供 CSV、可打开的 HTML 表格和 PNG 截图。

## 离线导览

打开[全网导览](results/network.html)可筛选线路、搜索起点站。也可打开[沿线景点](results/01-line-attractions.html)或[一次换乘](results/02-one-transfer.html)即可查看，页面之间可以互相切换。离线打开时请保留 results 目录结构。

## 复现

在项目目录下执行以下命令。脚本读取 data 下的源表，生成并重新解析 RDF/XML，对读取后的 RDF 执行 queries 下的查询，更新结果表格。

```powershell
python -m pip install -r requirements.txt
python run.py
```

查询脚本使用 RDFLib 执行。也可以在 Protégé 中打开 RDF 文件，再将对应的 .rq 文件粘贴到 SPARQL Query 视图运行。截图来自浏览器打开实际查询生成的 HTML。

正式提交时，将设计说明、RDF 和应用文档连同其引用的查询及截图放入以实际组号命名的「第X组」提交包。
